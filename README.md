# VitePress Starter

A minimal VitePress documentation site.

## Pre-installed Packages

- **[vitepress-plugin-llms](https://github.com/okineadev/vitepress-plugin-llms)** `^1.10.0` - LLMs.txt support for VitePress, generating AI-friendly content endpoints.
- **[vitepress-mermaid-renderer](https://github.com/sametcn99/vitepress-mermaid-renderer)** `^1.1.8` - Mermaid diagram rendering support for VitePress.

## 🚀 Development

```bash
pnpm install
pnpm dev
```

## 📦 Build

```bash
pnpm build
```
